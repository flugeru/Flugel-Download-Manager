## 3. Functional & Architecture Gap Inventory

1. **P0-A: Single-Instance Application & IPC Forwarding**
   - *Current Defect*: Launching a second `FlugelDownloadManager.exe --url <url>` (or browser NativeHost invocation when desktop is already open) fails with `IOException` on `instance.lock` and shows a modal startup error instead of forwarding the request to the running desktop instance.
   - *Required Fix*: Implement a same-user Named Pipe server (`FlugelDownloadManager.IPC.<UserSidHash>.<DataDirHash>`) inside the running `FlugelDownloadManager.exe` instance. When a second `FlugelDownloadManager.exe` or `Flugel.NativeHost.exe` runs, it connects to the pipe, sends the structured enqueue/media request, brings the running window to foreground with the prefilled Add/Media confirmation dialog (or queues it), and returns `{ "version": 1, "status": "accepted-for-confirmation", "forwardedToRunningInstance": true }`.

2. **P0-B & Mandatory Requirement: Real Browser Extension + Video Player Detection ("Download this video" Floating Balloon)**
   - *Current Defect*: Extension only registers a `contextMenus` item; no content script, no HTML5 `<video>` detection, no floating "Download this video" button, no MP4/WebM/HLS (`.m3u8`)/DASH (`.mpd`) quality/format discovery, no iframe support, no popup UI for global/per-site balloon toggles, no opt-in download interception, and no real Chrome/Edge browser execution test.
   - *Required Fix*:
     - Content script (`content-script.js`, `all_frames: true`) observing `<video>` elements and `<source>` children across initial DOM and dynamic SPA mutations (`MutationObserver`, `ResizeObserver`, `IntersectionObserver`, fullscreen/scroll/resize events).
     - Shadow-DOM isolated floating widget ("Download this video" / "Baixar este vídeo") anchored at the top-right of visible video players without blocking native playback controls, expanding on click to show all discovered media streams/formats/resolutions (e.g., `1080p MP4`, `720p WebM`, `HLS 1080p/720p/480p (.m3u8)`, `DASH (.mpd)`) with file size/bitrate when known.
     - Background service worker (`service-worker.js`) correlating `webRequest` media responses (`video/*`, `audio/*`, `.mp4`, `.webm`, `.m3u8`, `.mpd`) and parsing non-protected HLS master/media playlists and DASH MPD representations to list selectable qualities and pass segment/stream details to Flugel Download Manager.
     - Extension Action Popup (`popup.html` / `popup.js`) with Global Enable/Disable toggle, Per-Site Enable/Disable toggle (`chrome.storage.local`), Auto-Intercept Downloads toggle, and manual URL send.
     - End-to-end automated + visual verification in real Microsoft Edge (`msedge.exe`) and Chromium (`chrome.exe`).

3. **P1/P2: Core Engine Enhancements (`Flugel.Core`)**
   - Preserve all 40 existing engine tests without regression while adding:
     - **Category Classification & Per-Category Folders**: Automatic category assignment (`Compressed`, `Documents`, `Music`, `Programs`, `Video`, `General`) by extension with configurable extension rules and per-category default subdirectories.
     - **Content-Disposition Filename Resolution**: Safe parsing of `Content-Disposition: attachment; filename=...` / `filename*=UTF-8''...` when the user has not forced a custom filename, with strict path-traversal and reserved-name sanitization.
     - **Named Queues & Queue Scheduler**: Multiple queues (`Main`, `Sync`, custom), queue start/stop state, per-queue max concurrency, daily start/stop time windows, and day-of-week masks.
     - **Global & Per-Download Speed Limiting**: Token-bucket / throttled stream reading in `FetchAsync` honoring both global `MaxSpeedBytesPerSecond` and per-job `MaxSpeedBytesPerSecond` dynamically.
     - **Proxy & Request Context (Headers / Basic Auth / Referrer / User-Agent)**: Optional HTTP(S) proxy configuration and per-download `Referrer`, `UserAgent`, and optional `Authorization` (never logged to `events.jsonl` or exposed in UI summaries).
     - **HLS (`.m3u8`) & Multi-Segment Media Stream Assembly**: Native support in `Flugel.Core` for downloading non-protected HLS media playlists (fetching and concatenating `.ts` / `.m4s` media segments sequentially/concurrently with progress reporting) so selecting an HLS quality from the browser video balloon downloads the complete playable media stream!
     - **Import / Export**: Export and import download lists in `.txt` (URL list) and `.shb.json` (structured Flugel Download Manager export) formats.
